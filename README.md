# Veritas Community

Veritas Community brings people together for meaningful dialogue, shared learning, and mutual support in living out truth together.

## Local preview

```bash
npm install
npm run dev
```

The local development server provides the preview URL after startup.

## Mission

We are called to "Be Examples of 'The Way, The Truth and The Life' As He Intended" by creating spaces where individuals and families can come together for purposeful gatherings that explore faith, share experiences, and support one another on their spiritual journeys.

## Website Goal

This website transforms our former divorce mediation platform into a vibrant community hub focused on:
- Community Gatherings: Spaces for shared learning and growth
- Truth & Discernment Councils: Guided discussions for faith exploration
- Life Coaching & Mentorship: Support for living in alignment with Christian values

The new platform emphasizes building stronger families, healthier communities, and more resilient individuals through honest conversation and mutual support.
